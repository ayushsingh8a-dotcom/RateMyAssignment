# Rate My Assignment

Rate My Assignment is an AI-powered assignment evaluation tool for students.

Upload your complete assignment as a PDF, image, or text file and get an AI-generated evaluation with an overall score, grade, question-by-question feedback, strengths, weaknesses, and suggestions for improvement.

## Features

- Upload PDF, JPG, PNG, or TXT assignments
- AI automatically identifies questions and answers
- Overall score out of 100
- Letter grade
- Performance breakdown
- Question-by-question grading
- Strengths and areas to improve
- Personalized suggestions
- Drag and drop uploads
- Dark and light mode
- No assignment files are permanently stored

## Privacy

Assignments are processed to generate feedback and are not intentionally stored permanently by the application.

## Disclaimer

AI-generated grades and feedback are intended as an educational aid and should not be considered an official academic evaluation.
